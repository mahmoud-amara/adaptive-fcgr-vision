## 3. Statistical Testing Audit & Methodological Assessment

### 3.1 Permutation Test Implementation
- **Procedure**: [`uncertainty.py:L48-87`](file:///d:/Image%20Research%20paper/src/adaptive_cgr_vision/evaluation/uncertainty.py#L48-L87) concatenates predictions across outer folds into $N=150$ sample pairs. For each of 1,000 permutations, sample predictions are swapped pairwise with probability $0.5$, and the Macro-F1 score difference is recalculated.
- **Holm-Bonferroni Correction**: Correctly implemented in [`run_ablation_study.py:L226-236`](file:///d:/Image%20Research%20paper/scripts/run_ablation_study.py#L226-L236). $p$-values are sorted and adjusted via $p_{\text{Holm},(i)} = \min(1.0, p_{(i)} \cdot (4 - i + 1))$, enforced to be non-decreasing.

### 3.2 Methodological Critique for Grouped CV
- **Limitation**: Sample-level prediction swapping treats all 150 test instances as independent observations. Because test instances are grouped into 5 outer CV folds and originate from sequence clusters, sample-level swapping ignores group correlation and outer fold structure, overestimating degrees of freedom.
- **Reporting Status**: The reported permutation test $p$-values must be treated as **exploratory indicators** rather than strict parametric hypothesis proofs.

### 3.3 Verified Statistical Findings
1. **SVM-RBF Multi-Family Synergy**:
   - `All_Families_Combined` (0.9200 F1) achieves large, statistically significant gains over every single feature family:
     - vs `Frequency_Spectrum_Only` (0.7368): $\Delta = +0.1831, p_{\text{raw}} < 0.0001, p_{\text{Holm}} < 0.0001$ (**Significant**)
     - vs `GLCM_Texture_Only` (0.7905): $\Delta = +0.1295, p_{\text{raw}} < 0.0001, p_{\text{Holm}} < 0.0001$ (**Significant**)
     - vs `Edge_Boundary_Only` (0.7975): $\Delta = +0.1225, p_{\text{raw}} < 0.0001, p_{\text{Holm}} < 0.0001$ (**Significant**)
     - vs `Spatial_Distribution_Only` (0.8532): $\Delta = +0.0668, p_{\text{raw}} = 0.0140, p_{\text{Holm}} = 0.0140$ (**Significant**)
2. **Random Forest Single-Family High Performance**:
   - `GLCM_Texture_Only` alone achieves $0.9331 \pm 0.0371$ F1.
   - `All_Families_Combined` vs `GLCM_Texture_Only`: $\Delta = -0.0080, p_{\text{raw}} = 0.5550, p_{\text{Holm}} = 1.0000$ (**Not Significant**).
   - Random Forest decision trees effectively construct non-linear splits on single high-capacity feature families.

## 4. Split & Data Leakage Audit

### 4.1 Outer Fold Isolation
- **Splits Manifest**: Outer folds strictly follow [`splits_full.csv`](file:///d:/Image%20Research%20paper/data/manifests/splits_full.csv).
- **Feature Scaling Isolation**: `scaler = StandardScaler()` is fit strictly on training fold indices `X_tr` for each representation ([`run_ablation_study.py:L156-158`](file:///d:/Image%20Research%20paper/scripts/run_ablation_study.py#L156-L158)). Test set features `X_te` are transformed using training parameters only. Zero feature scaling leakage occurs.

### 4.2 MinHash Homology Isolation Scope
- **What MinHash Establishes**: 149 distinct single-linkage clusters were formed across 150 genomes at 95% ANI using MinHash bottom-$1000$ sketching ($k=21$). Inter-fold group overlap is exactly zero.
- **What MinHash Does NOT Establish**: Does not guarantee complete absence of sequence homology (e.g. shared mobile genetic elements or sub-95% ANI regions). Full alignment-based ANI (FastANI) would be required for absolute proof.

## 6. Audit Conclusions & Presentation Guidance

### 6.1 Verified Findings (Safe to Claim in Course Presentation)
1. **Multi-Family Vision Synergy for Kernel Classifiers (SVM-RBF)**: Combining GLCM, Spatial, Frequency, and Edge feature families achieves $91.95\%$ F1, significantly outperforming any individual feature family alone ($73.43\%\text{--}85.09\%$ F1, $p_{\text{Holm}} \le 0.0140$).
2. **Spatial Distribution Signal**: Spatial moments and density distributions represent the single strongest individual feature family for SVM-RBF ($85.09\%$ F1).
3. **Random Forest High Single-Family Capacity**: Random Forest achieves $\ge 91\%$ F1 using GLCM, Spatial, or Frequency families alone, showing strong non-linear decision boundary construction.
4. **$69.4\times$ Dimensionality Reduction**: Compressing 4,096 raw pixels into 11–59 descriptors maintains high classification accuracy while drastically reducing model complexity.

### 6.2 Claims That Must Be Weakened or Withheld
1. **Do NOT claim parametric statistical proof from permutation tests**: Acknowledge that permutation tests are sample-level exploratory indicators on pooled out-of-fold predictions.
2. **Do NOT claim "Adaptive Fusion Superiority"**: The ablation study uses fixed feature scaling; combined feature representation success is driven by multiscale feature diversity rather than adaptive weighting.
